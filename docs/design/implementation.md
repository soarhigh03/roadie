# 디자인 적용 기록

2026-11-16에 Figma MCP로 최신 파일을 확인했다.

원본: https://www.figma.com/design/JfTYX9XzesZxlyADnpzlR2/Roadie

4개 페이지: 01 Brand studio, 02 Foundations, 03 Components, 04 Vehicle experience.

브랜드 6:2, 로고 6:40, 파운데이션 7:114, 컴포넌트 8:114, 캐릭터 규칙 6:103 및 모든 요청 화면의 디자인 컨텍스트와 스크린샷을 확인했다. 출발 5:305, 듣기 5:338, 말하기 5:380, 안내 대기 5:414, 관심사 5:445, 휴식 5:482, 오류 5:518, 설정 5:551, 작은 창 5:586, 마이크 끄기 9:335, 조용한 동행 11:347, 브리핑 재생 11:384, 검토 메뉴 9:368을 기준으로 구현한다.

원본 3:116의 입체 이미지를 캐릭터 영역에 사용한다. 배너는 기존 대표 보드 6:2의 로컬 PNG이다. 화면 전체 스크린샷을 앱 UI로 사용하지 않는다. UI의 텍스트, 상태, 버튼은 Compose로 구현한다. 주행 화면에서 반복 애니메이션은 사용하지 않는다.

색상: Pink #F3A6CE, Lime #DDFF82, Cream #FFFEF5, Silver #BFC3CB, Ink #24262B, Night #16181C. 낮 surface #F4F2E8, 낮 secondary #64666C, 밤 surface #22252B, 밤 secondary #A9ADB3.

원본의 1280 x 720 레이아웃과 560 x 720 작은 창을 기준으로 가변 배치한다. 기본 모서리 24, 캐릭터 패널 모서리 32, 8 단위 간격, 최소 64dp 이상의 주요 조작 영역을 사용한다. Android sp 글자 크기 설정을 존중한다.

Figma 시안의 호출어와 자동 끼어들기 문구는 지원을 확인하지 못했으므로 버튼으로 명시적으로 대화를 재개하는 문구로 바꾼다. 내비의 안내 발화 시작 이벤트는 경로 시작 이벤트와 구분한다.
